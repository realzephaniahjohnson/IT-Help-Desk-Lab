# Ticket 001 - PDF Files Won't Open

## Issue
User reported that PDF files would not open.

---

## Environment
- Windows 11 Pro
- VMware Fusion
- Adobe Acrobat Reader

---

## Symptoms
- Double-clicking a PDF file did not open the document.

---

## Investigation
- Contacted user.
- Obtained PC Name: WJN001.
- Verified default PDF application.
- Determined the file association was incorrect.

---

## Resolution
- Updated the default application to Adobe Acrobat Reader.
- Tested multiple PDF files.
- User confirmed the issue was resolved.

---

## Root Cause
Incorrect `.pdf` file association.
